A red team crew based on the Mediterranean coast, running offensive security engagements, research, and custom tooling for clients anywhere.

## 🎯 What We Do

<table width="100%">
<tr>
<td width="50%" valign="top">

**⚔️ Adversary Simulation**
Full-scope red team engagements modeling real threat actor TTPs — initial access, lateral movement, persistence, and exfiltration, mapped to MITRE ATT&CK.

**🛠️ Custom Tooling**
We build our own recon, exploitation, and reporting tools rather than relying solely on off-the-shelf frameworks — this org is where that tooling lives.
